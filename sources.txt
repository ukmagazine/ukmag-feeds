# UK Magazine - feed sources
#
# One URL per line. Lines starting with # are ignored.
#
# Two formats are supported:
#   - RSS / Atom feeds
#   - Google News XML sitemaps, for publishers that dropped RSS.
#     A sitemap carries a title and a date but NO summary, so
#     News_Body arrives empty and the full text comes from Jina.
#
# A source only works if its ARTICLE domain is in the Whitelist E-Gate
# filter (Core Engine, link 20 -> 36). A missing domain means the
# article is fetched, sent, and then silently discarded.
#
# Domains required by the ACTIVE list below:
#   bbc.co.uk  theguardian.com  independent.co.uk  gov.uk
#   timeout.com  ianvisits.co.uk  secretldn.com
#
# Measured 14 August 2026: approx 75 new articles per day.
